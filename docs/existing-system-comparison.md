# DeepCheck - Existing System Comparison

## 1. Purpose

This document compares the intended role of DeepCheck with common categories of existing deepfake-detection solutions.

## 2. Existing Solution Categories

Existing approaches generally include:

- research-oriented detection models;
- browser or web-based detection services;
- forensic analysis tools;
- media verification platforms;
- platform-specific moderation systems.

These solutions may differ in supported media types, model architecture, accessibility, explainability, and deployment model.

## 3. DeepCheck Position

DeepCheck is primarily an educational and experimental prototype. Its main value is the integration of a complete detection pipeline into a project that can be inspected, tested, and developed by the project team.

| Criterion | DeepCheck Prototype |
|---|---|
| Image upload | Yes |
| REAL/AI classification | Yes |
| ML integration | Yes |
| Web interface | Yes |
| Multilingual UI | Yes |
| Video detection | Future work |
| Production-grade forensic guarantee | No |
| Transparent project repository | Yes |

## 4. Differentiation

The project emphasizes integration and transparency. The repository contains frontend, backend, ML-related code, testing documentation, and project-management evidence.

## 5. Limitation

A direct numerical comparison with commercial or research systems should only be made after obtaining comparable datasets, evaluation protocols, and measured results. No unsupported performance comparison is claimed in this document.
